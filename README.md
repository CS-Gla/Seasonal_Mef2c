# Seasonal_Mef2c
A repository for the paper MADS-box transcription factors regulate seasonal physiology in mammals.

Detailed within this repository is the code necessary to carry out all analysis presented within the paper. The scripts are presented in two broad groups "Orthogroup_analysis" and "PFAM_analysis", however they are designed to work together. No data is presented here. Required data inputs for each script will be detailed. Some scripts have been slightly edited from original versions to protect information regarding email addresses and file structure related to the University of Glasgow's high performance computing service.

Scripts;
  - ortho_scan.sh: A PBS/Torque script designed to run on a high performance computing cluster. Can be run on other UNIX systems with some modification. Required inputs are full proteomes, acquired from the UniProt online database (https://www.uniprot.org/). This script builds de-novo orthogroups using proteomes as input data. Requires an installed conda environment containing the orthofinder package.
  -  multi_animals.RMD: An rmarkdown script designed to perform WGCNA like analysis on on orthogroup-level expression data from multiple species. Required inputs are ORthogroups.tsv (produced by ortho_scan.sh) and expression matrices for each species represented within the orthogroup analysis. Note gene names must be identical to orthogroup input names.
  -  ortho_analysis.RMD: An rmarkdown script designed to perform WGCNA like analysis on on orthogroup-level expression data from multiple species. This script performs preservation analysis between WGCNA_like objects from multiple species. Required inputs are ORthogroups.tsv (produced by ortho_scan.sh) and expression matrices for each species represented within the orthogroup analysis. Note gene names must be identical to orthogroup input names.
  -  proteome_hmmscan.sh:  A PBS/Torque script designed to run on a high performance computing cluster. Can be run on other UNIX systems with some modification. Required inputs are full proteomes, acquired from the UniProt online database (https://www.uniprot.org/). This script builds de-novo pfam family assignments from provided proteomes. Requires an installed conda environment containing the HMMER package.
  -  pfam_analysis.R: An rmarkdown script designed to perform analysisa and plot pfam families identified using proteome_hmmscan.sh. Required inputs are pfam family analyis for each species (.domtblout files) and expression matrices from each species represented within the pfam family analysis. Note gene names must be identical to orthogroup input names.
